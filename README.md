# Pinksem — IT Services Website

A modern, responsive multi-page website concept for an IT services company, built using HTML, CSS, and Bootstrap.

## Overview

Pinksem presents a professional digital services brand with a clean layout, navy-and-violet color palette, responsive sections, and dedicated pages for company information, services, industries, and contact details.

## Pages

- **Home:** Company introduction and featured services
- **About:** Company concept, mission, vision, and values
- **Services:** Web development, custom software, cloud solutions, UI/UX, AI concepts, and IT consulting
- **Industries:** Examples of industries that can benefit from digital solutions
- **Contact:** Contact information and a front-end inquiry form

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- Responsive web design

## Features

- Multi-page website with shared navigation
- Responsive layouts for desktop and mobile screens
- Reusable styling and consistent branding
- Local Bootstrap stylesheet
- Local image assets
- Interactive hover effects using CSS
- No JavaScript required
